Story Graph Studio

Upload a book. Watch its cast of characters take shape as a graph.

Upload TXT, PDF, DOCX, or EPUB files and generate an interactive story graph. Jobs, checkpoints, artifacts, and status information are persisted in the database, allowing processing to continue across application restarts.

Bring your own Gemini API key. Story Graph never stores your API key. It's used only for the current processing request and discarded afterward.

Don't have a key? Sign in with your Google account and create one from Google AI Studio . The official documentation is available here.

If a job is paused or later resumed, you'll be asked to provide your API key again — handy if your previous quota has run out.
